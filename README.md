Bayan (بيان) is a bilingual Arabic–English NLP engineering project designed to analyze citizen feedback through a complete end-to-end pipeline. It includes text preprocessing and PII masking, topic classification, named entity recognition, extractive question answering, Arabic-specific normalization and segmentation, and bilingual semantic search using FAISS with reranking. The project also covers model evaluation through confidence intervals, sliced metrics, behavioural testing, manual error analysis, and model cards, as well as CPU-based inference benchmarking and ONNX/INT8 optimization experiments. Each lab builds on the previous one, turning individual NLP components into a structured and reusable system supported by measured results and engineering evidence.

Developed by Shoog Algasim as part of the SDAIA training program, under the supervision of Aljawhara AlBahlal.
